Install it in about a minute

Code Scout isn't on the Chrome Web Store, so there's no "Add to Chrome" button. You download it and point your browser at the folder.

  1. Download and unzip

    Unzip the file and move the folder somewhere it can stay, such as Documents. Your browser runs the extension from that folder, so don't leave it in Downloads.

    Download the zip

  2. Turn on Developer mode

    Open the extensions page by pasting this into the address bar, then switch on Developer mode at the top right.

    chrome://extensions

  3. Load the folder

    Click Load unpacked and pick the unzipped folder, the one with manifest.json inside. Code Scout appears in the list. Pin it from the puzzle-piece menu to keep its button in the toolbar.

The browser may now and then ask whether to keep developer-mode extensions on. Choose to keep them. A web page can't open chrome://extensions for you, which is why you paste it.

What it does

Finds codes wherever they are

A small ▶ button sits next to every code on a page. Type one into any search box and a chip offers Open or Search. Right-click a link or selected text to do the same.

Opens it where you want

The trailer on javtrailers.com, or the same video on any site in your list. Add your own sites with a URL pattern. Alt+Shift+J opens the selected code, Alt+Shift+L opens it everywhere.

Tells you what a video is

A code alone says little. Each one has a card with the cover, title, release date, length, performers, studio, series and genres, and links to more like it.

Remembers for you

Star videos, performers and genres. Keep a Watch later list. Codes you've opened get a grey ✓ on every page, so the ones you haven't seen stand out.

Better video players

A small toolbar on every video: faster loading for streamed video, a quality menu, download as MP4, speed from 0.25× to 4×, picture-in-picture, and the same keyboard keys on every site.

English subtitles

Reads Chinese or Japanese subtitles in the picture and covers them with English, all on your computer (Chrome 138 or later). Or pick a subtitle file for the video's code from SubtitleCat.

Hides it in one key

Someone walks in: Alt+Shift+H pauses every video, mutes the tabs and tucks them into a minimised blank window. Press it again and they're back where they were.

Stops ad pop-ups

Clicks on Code Scout's own buttons never reach a site's ad scripts. Switch on the pop-up blocker for a site to stop its pop-unders and redirect tricks too.

Yours to arrange

Light or dark, six accent colours, quick links in groups, sorting and filters on every list, and a backup file with everything in it for moving to another computer.

Updating

A browser doesn't update an extension installed this way. Code Scout's popup shows a line when a newer version is out.

  1. Download the new zip, from the popup's Get it button or from this page.
  2. Unzip it and put its files over the ones in the folder you installed from, replacing them.
  3. On chrome://extensions, press the reload arrow on Code Scout.

Your favourites and settings stay. Don't press Remove to update: removing the extension deletes what it has saved.

Questions

What does it keep, and where does it go?

Favourites, seen codes and settings are kept in your browser on your computer. There is no account and no server of its own. It contacts GitHub once a day to check for a newer version, and the video and subtitle sites when you look a code up. Favourite videos are also saved to a bookmarks folder called Code Scout favourites.

Why does the browser say it can read every site?

Codes can appear on any page, so the extension has to look at the pages you open to find them and to add its video toolbar. You can turn its buttons off for a site from the popup. The source is on GitHub if you want to check what it does.

Which browsers does it work in?

Chrome, Edge, Brave, Vivaldi, Opera and other browsers built on Chromium, on Windows, macOS and Linux. It doesn't work in Firefox or Safari, or on phones.

The extension disappeared, or shows an error after I moved a folder.

The browser runs it from the folder you picked. If that folder is moved or deleted, press Load unpacked again and pick it in its new place. Your favourites and settings come back with it.

How do I remove it?

On chrome://extensions, press Remove on Code Scout, then delete the folder. To keep your lists, save them first with Settings → Backup → Export to a file.
